# Influence India Services — Official Platform

Official repository for Influence India Services (`https://influenceindiaservices.com`), India's leading single-vendor contract staffing, managed workforce deployment, and Onsite Skill Training Program (OSTP) partner headquartered in Bengaluru.

## Canonical Git Repository

The ONLY authoritative and official GitHub repository for this project is:
- **Repository URL:** `https://github.com/Karthik-bhandarkar/influence-india-client-demo`
- **Default Branch:** `main`

> **IMPORTANT:**  
> All updates, CI/CD integrations, feature branches, and production releases must be pushed exclusively to `https://github.com/Karthik-bhandarkar/influence-india-client-demo`. Do not push to any other repository.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4 with `@tailwindcss/vite`
- **Animations:** Framer Motion, Lenis Momentum Smooth Scroll
- **SEO & Structured Data:** Dual-Funnel Architecture, Next.js / React Metadata, Comprehensive Multi-Entity JSON-LD Schema
